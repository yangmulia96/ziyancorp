# ZIYAN Cybersecurity Content (Edukatif)

Skill untuk menghasilkan **konten edukatif/defensive** tentang AI security.
Bukan offensive hacking — sesuai prinsip etik ZIYAN (jangan jual yang bikin klien rugi).

## Sumber Riset (terverifikasi)
1. **OPSWAT** (2025-09-08) — "AI Hacking: How Hackers Use AI in Cyberattacks"
   - AI hacking = pakai AI utk otomatisasi serangan (gen code, evasion, recon)
   - Tools: HackerGPT, WormGPT (offensive LLM)
   - Pola: democratization (LLaMA fine-tune offense), barrier to entry turun
2. **Checkpoint** (2025-11-30) — "AI Agents Hacking"
   - AI agent = semi-otonom, bisa aksi nyata (klik, isi form, booking)
   - Risiko: akses data sensitif (CS, finance, healthcare)
   - Hijacking agent = goal baru penjahat → exfiltration, manipulasi

## Format Konten (3 Pilar ZIYAN)
- **YouTube Faceless**: narasi + infografis (NotebookLM 8 artefak)
- **TikTok/Short**: hook 3 detik, awareness tips
- **Blog**: SEO article + affiliate (produk keamanan)

## Struktur Naskah (Template)
```
Hook: "AI sekarang bisa meretas sendiri — begini cara kerjanya"
Body:
  1. Apa itu AI hacking (democratization)
  2. Contoh: phishing AI-generated, deepfake voice
  3. AI agent sebagai target (hijacking)
  4. Cara defend: 2FA, monitor agent, least-privilege
CTA: "Subscribe untuk tips keamanan AI"
```
