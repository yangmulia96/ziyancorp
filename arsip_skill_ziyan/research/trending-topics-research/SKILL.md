# Trending Topics Research → Content Brief

## When to use
- User asks to find / research trending topics, hot subjects, or content ideas in a domain (tech, AI, finance, etc.), especially with an audience or monetization angle.
- Output is a ranked, classified Markdown list ready to hand to a writer/editor or paste into a script.

## Workflow
1. **Clarify the brief** (if not already given): domain/niche, target audience, content format (Shorts vs long-form), and any angle (e.g., money/investments, US prime-time ET). If the prompt specifies all of this, proceed.
2. **Fetch in parallel** via terminal `curl` — issue multiple independent `curl` calls in one turn (see `references/source-endpoints.md`). Sources:
   - **Hacker News API** — `topstories.json` → top ~25 IDs → fetch each `item/<id>.json`. Score + comment count = strong viral signal.
   - **Google News RSS** — `news.google.com/rss/search?q=<query>+when:2d&hl=en-US&gl=US&ceid=US:en` (swap query/locale). Best for mainstream + money/stock angles and cross-outlet confirmation.
   - **Tech press RSS** — techcrunch.com/feed/, theverge.com/rss/index.xml, arstechnica.com/feed/.
   - **Reddit** — `reddit.com/r/<sub>/hot.json?limit=25` — frequently rate-limited (returns HTML). Optional fallback only.
3. **Parse** with a Python script written to disk (use `write_file`) and run via terminal `python3 script.py`. Do **not** use `execute_code` for the fetch/parse loop — subprocess calls are blocked on this host. A ready-made, re-runnable parser lives at `scripts/parse_trending.py`: copy it into the working dir and run `python3 parse_trending.py`. It reads the curl outputs by relative name (`hn_top.json`, `hn_*.json`, `gn_*.xml`, `tc.xml`, `at.xml`), so run it FROM the research dir.
4. **Curate & rank**: dedupe, filter to the niche/angle, rank by viral potential. Signals: HN score/comments, repeat coverage across independent outlets, and relevance to the requested angle (e.g., investment impact).
   - **Niche-fit override (key lesson, verified 2026-08-15):** the parser's top raw score is NOT always the right publish topic. `parse_trending.py` scores by cross-outlet + cross-query overlap, which can crown a story that is off-audience. Real example: a run ranked *"Minnesota iron ore → lower-cost semiconductor"* #1 (science/materials, off-niche for a Tech/AI/Business/Finance channel) while the strongest video-grade finance/tech item *"Is Taiwan Semiconductor too expensive?"* sat at rank 8. **Always apply a niche-fit filter:** among the ranked list, pick the highest-scored item that matches your channel's audience angle — do NOT blindly use rank-1. Capture the chosen `primary_topic` + its real `primary_source_url` into downstream state/pipeline for staging. **Ranking technique that works well here:** Google News returns the SAME story under several query files (`gn_ai.xml`, `gn_fin.xml`, `gn_chip.xml`) with slightly different headlines, so exact-string dedupe under-ranks real trends. The bundled `scripts/parse_trending.py` (a) buckets by normalized title, (b) greedily merges near-duplicates across queries with token **Jaccard ≥ 0.6** (or subset match), then (c) scores each story as `outlets*7 + (queries−1)*6 + HN_boost` — so both cross-outlet AND cross-topic (multi-query) coverage raise the rank. Tune the `>=7` cutoff in the script for ~15 items.
5. **Emit the Markdown brief** using `templates/content-brief.md`: per topic give Judul, Ringkasan, Mengapa relevan sekarang, Skor viral /10, Kaitan uang/investasi, Sumber (real URL + date), and Angle video (Shorts vs Long idea).
6. **Append `### Catatan Sumber Gagal`** listing any source that returned no usable data (e.g., Reddit HTML block) so the user knows what's missing.

## Hard rules
- **Only real URLs you actually fetched.** Never fabricate headlines, scores, outlet names, or links. If a source failed, say so in the failure section — do not invent a substitute.
- Keep the deliverable as direct Markdown in the final reply, not just a description of it.

## Pitfalls / host gotchas (Windows + git-bash host)
- **No `/tmp`.** Create a working dir under the Windows home, e.g. `/c/Users/<user>/research`, and `cd` into it before every `curl`.
- **CRITICAL curl pitfall (2026-08-14, verified):** `curl ... -o /c/Users/<user>/research/file.xml` with an **absolute MSYS `/c/...` path** FAILS with **exit code 23 (write error)** and writes NOTHING — even when the URL is reachable (HN/TechCrunch fetched fine, but Google News with absolute `-o` returned 0 bytes + exit 23). FIX: `cd /c/Users/<user>/research` FIRST, then use a **relative** `-o file.xml`. Relative `-o` after `cd` works; absolute `/c/...` `-o` does not. Diagnose fast with `curl -sS -v "...url..." -o rel.xml 2>err; echo "EXIT=$?"` — a write error shows `EXIT=23` and 0-byte file.
- **`python3` is Windows-native** and does **not** understand MSYS `/c/...` paths. In scripts use `WORK="."` (relative) and run from the working dir; pass files by relative name.
- **CRITICAL python-write pitfall (2026-08-14, verified):** if YOU write a NEW python script (beyond the bundled `parse_trending.py`) that writes files using an absolute MSYS path like `/c/Users/arija/workdir/videos/2026-08-14/script.md`, Windows-native python silently rewrites it to `C:\c\Users\arija\workdir\...` (double drive-prefix) — the file "disappears" from the intended dir and the run still reports success. FIX: use a **Windows-native path with forward slashes** (`C:/Users/arija/workdir/...`) or a **relative path** run from the target dir. If staged files seem missing, check `ls /c/c/Users/...` (the misplaced location).
- **Free-model JSON is fragile (9Router):** when generating structured assets (YouTube metadata, social posts) via `groq/llama-3.3-70b-versatile` or `openrouter/poolside/laguna-s-2.1:free`, asking for strict JSON FAILS — the model emits literal newlines inside string values (`Invalid control character` / `Unterminated string` on `json.loads`/`raw_decode`), or returns truncated JSON when it hits `max_tokens`. ROBUST FIX: request a **delimited per-line format** (`TITLE: ...`, `DESC: ...`, `X1: ...` .. `X5: ...`, `TG: ...`, `LI: ...`, `BLOG: ...` — one value per line, NO newlines inside a value, NO markdown), then extract each field with regex `^LABEL:\s*(.*)$` (re.MULTILINE | re.IGNORECASE). Never rely on the model returning parseable JSON. Wrap every call in a fallback: try the requested model, on ANY Exception fall back to `groq/llama-3.3-70b-versatile`. NOTE: `openrouter/poolside/laguna-s-2.1:free` has been observed returning an empty/invalid body (`Expecting value: line 1 column 1`) — the broad-Exception fallback handles it; do not assume the requested model will answer.
- **`execute_code` is blocked for subprocess** (cron-mode safety) — use terminal `curl` + on-disk Python scripts instead.
- **`&` backgrounding DITOLAK di `terminal()` foreground** — error: *"Foreground command uses '&' backgrounding. Use terminal(background=true)..."*. Untuk fetch paralel banyak URL, JANGAN pakai `cmd & cmd & wait` dalam satu call. Ganti dengan: (a) ISSUE BEBERAPA `terminal()` call dalam SATU turn (runtime menjalankannya paralel), atau (b) chain berurutan dengan `&&` di dalam satu command. Terbukti 2026-08-14: pola `&` gagal (exit -1), pola `&&` berhasil. (`terminal(background=true)` untuk long-lived server, bukan untuk paralel fetch cepat.)
- **The Verge RSS** can return 0 bytes with a normal browser UA — retry with `-A "Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)"`.
- **Reddit `.json`** often returns an HTML error page (rate-limit/block) → `json.load` fails. Don't rely on it; fall back to other sources and record it under Catatan Sumber Gagal.
- **Google News item links** are tracking URLs (`news.google.com/rss/articles/...`) — they are real and functional; keep them and cite the publisher in text.
- **`chip` query noise (2026-08-04):** `q=chip` di Google News RSS cocok ke 'Chocolate Chip Cookie Day' & 'Blue-Chip Football' — polusi ranking (skor tinggi dari 2 outlet, menggeser topik semikonduktor asli ke bawah). Untuk sinyal tech/finance yang bersih, fetch `gn_chip.xml` dengan `q=semiconductor` (atau `semiconductor stocks` / `Nvidia`). Parser greedy-merge Jaccard tidak bisa bedakan 'chip' makanan vs semikonduktor, jadi perbaiki di SUMBER query, bukan di parser.
- **Stale `gn_*.xml` accumulation:** file `gn_*.xml` dari run SEBELUMNYA tetap ada di dir kerja & ikut di-glob parser (menambah coverage, tapi bisa basi). Bersihkan atau pakai dir kerja fresh tiap run agar tanggal fetch konsisten.
- **Ticker-aggregator noise (2026-08-10):** Google News RSS mengembalikan halaman auto-generated Yahoo Finance / StockAnalysis ("<TICKER> stock price, news, quote and history", "Dividend Analysis", "Quote & History") yang mendominasi rank #1 by outlet count tapi BUKAN cerita nyata — tidak layak jadi naskah video. Filter di parser via `is_noise()` (cek substring) SEBELUM scoring. Untuk pick PRIMARY video, prefer topik *narrative* cross-outlet (bukan ticker page). Sudah ditangani di `scripts/parse_trending.py`.
- **HN item JSON quirks (2026-08-10):** sebagian `hn_*.json` deserialize jadi `list` (bukan dict) atau `null` → `scripts/parse_trending.py` sudah guard `if not isinstance(d, dict)`. (Field `time` HN memang bertipe **int** Unix timestamp, tapi parser versi terpasang tidak membaca `time`, sehingga tidak terdampak.)
- **HN item-fetch CR trap (2026-08-14, verified):** fetch item HN via `while read id; do curl ...; done < hn_ids.txt` — `python3` (Windows-native) menulis `hn_ids.txt` dengan line-ending `\r\n`. git-bash `read` menangkap `123\r` sehingga URL jadi `.../item/123\r.json` → curl exit 3 "Malformed input to a URL function" & 0 byte (SELURUH item gagal padahal URL valid). FIX: `sed -i 's/\r$//' hn_ids.txt` SETELAH python tulis file & SEBELUM loop `while read` (atau `tr -d '\r' < hn_ids.txt > hn_ids2.txt`). Tanpa strip ini, fetch HN total gagal.

**Terminal `\$`-escaping trap (2026-08-16, verified):** saat menulis command `while read`/`for` di tool `terminal()`, JANGAN tulis `\$id` (backslash-dollar). Backslash mencegah ekspansi variabel bash → URL jadi literal `item/$id.json` & hanya 1 file `hn_$id.json` terbuat (loop 25x cuma overwrite 1 file → hasil `items=2`, bukan 25). FIX: tulis `$id` TANPA backslash. Berlaku untuk semua loop berbasis ekspansi variabel di terminal tool.

**Bundled `scripts/parse_trending.py` bisa HILANG / orphan dari disk (2026-08-16, verified):** `search_files` di host ini returns 0 untuk `parse_trending.py` walau SKILL.md + metadata skill menyebutnya (file mungkin tidak ter-copy ke working dir, atau reference orphan). FIX: (a) cek dulu `C:/Users/arija/AppData/Local/hermes/skills/research/trending-topics-research/scripts/parse_trending.py` lalu `copy` ke working dir, ATAU (b) tulis parser self-contained lalu `python3 parse_trending.py`. Algoritma wajib: (1) baca `hn_top.json`+`hn_*.json`, `gn_*.xml` (Google News), `tc.xml`, `at.xml`; (2) normalize title (lowercase, strip ` - Publisher`, buang punctuation), tokenize; (3) greedy-merge klaster via Jaccard token ≥0.6 ATAU subset; (4) skor = `outlets*7 + (queries-1)*6 + hn_boost`; (5) **DEFINISIKAN hn_boost = flat +8 bila ada HN score (JANGAN `min(hn,600)*0.1`)** — scaling lama bikin post HN (score 487 → +48.7) mengubur tren cross-outlet finance (score ~20) padahal itulah topik video-grade; (6) filter noise (ticker-agregator Yahoo/StockAnalysis: substring `stock price, news, quote`, `dividend analysis`, `quote & history`); (7) **niche-fit override**: di antara ranked, pilih item skor-tertinggi yang cocok audiens channel (Tech/AI/Business/Finance + angle uang) — JANGAN pakai rank-#1 mentah. Output `trends.json` + `trending_topics.md`.
- **Search engines (Google, Bing, Brave, DuckDuckGo) are bot-blocked from this host** — they return captcha/empty pages, `000` (connection refused), or SSL errors. Fallback for sourced facts: use `curl` on direct authoritative article URLs (works reliably) and `browser_navigate` for official/primary pages (e.g., YouTube Help). Do NOT rely on search-engine HTML to gather facts.

## Support files
- `references/source-endpoints.md` — exact curl commands, endpoints, HN fetch loop, and parsing notes.
- `templates/content-brief.md` — drop-in Markdown skeleton for the deliverable.
- `scripts/parse_trending.py` — re-runnable parser: from the research dir, reads HN + Google News (`gn_*.xml`) + TechCrunch + Ars Technica, merges near-duplicate headlines across queries via token-Jaccard, scores by cross-outlet + cross-query overlap + HN boost, and writes `trending_topics.md` per the template. Skips The Verge/Reddit (known host blocks).
