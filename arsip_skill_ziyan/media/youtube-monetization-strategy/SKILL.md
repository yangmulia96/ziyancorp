# YouTube Monetization Strategy (channel baru / 0 subs)

## Kapan pakai
- User minta strategi menghasilkan uang dari YouTube dengan channel baru (0 subs).
- Niche Tech / AI / Business / Finance, konten berbahasa Inggris, audiens internasional.
- Output yang diminta: tabel jalur monetisasi, rekomendasi eksekusi berurutan, taktik Shorts, produk affiliate, funnel ke bisnis, praktik aman.

## Langkah
1. **Verifikasi fakta resmi YPP** via `browser_navigate` ke YouTube Help (`support.google.com/youtube/answer/72851`) — jangan asumsikan threshold. Fakta resmi: 1.000 subs + 4.000 valid public watch hours **ATAU** 1.000 subs + 10 juta valid public Shorts views (90 hari); watch-time Shorts di Shorts Feed **TIDAK** dihitung ke 4.000 jam.
2. **Riset jalur pra-YPP** (affiliate, Patreon/Ko-fi, funnel ke jasa/AI Service Agency, sponsor langsung, course/info-product, merchandise) — urutkan by kecepatan cuan pertama.
3. **Ambil knowledge bank** di `references/youtube-monetization-strategy.md` (threshold, jalur, produk affiliate nyata, contoh kreator, funnel B2B, praktik aman).
4. **Susun tabel** Jalur | Kecepatan | Syarat | Cocok untuk compound daily? + 5 rekomendasi eksekusi berurutan (tandai mana yang bisa cuan <30 hari).
5. **Simpan deliverable** ke file (mis. `C:\Users\arija\<nama>.md`) — jangan print isi file ke chat kecuali diminta.

## Pitfalls
- Search engine (Google/Bing/Brave/DDG) **bot-blocked** di host ini → pakai `curl` pada URL artikel langsung + `browser_navigate` untuk halaman resmi/primer. Jangan andalkan HTML search engine untuk kumpulkan fakta.
- Jangan fabricate angka komisi affiliate persis — sebut "umum/publik" dan pakai nama program nyata (Jasper, HubSpot, Semrush, dkk).
- Hindari reused content / AI-generated spam — YouTube "reused / inauthentic content" = tidak eligible monetisasi. Buat konten original + disclose affiliate/AI.
