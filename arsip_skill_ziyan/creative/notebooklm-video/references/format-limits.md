# NotebookLM / Gemini Notebook — Format & Batasan Video

Diambil & diverifikasi 2026-07-31 dari dokumentasi resmi + pengujian langsung.

## 3 Format Video Overview
| Format | Durasi | Bahasa | Usia | Karakter |
|---|---|---|---|---|
| Short | ~60 dtk | HANYA Inggris | 18+ | Baru ("New!"), bite-sized |
| Explainer | mengikuti isi sumber | Inggris + Indonesia + lainnya | - | komprehensif, hubungkan ide |
| Cinematic | imersif | HANYA Inggris | 18+ | visual storytelling kaya |

## Gaya Visual (Classic, Whiteboard, Watercolor, dll)
- Hanya untuk pengguna 18+, TIDAK berlaku untuk Cinematic & Short.

## Generate
- Jalan di background server Google, bisa >30 menit.
- Tidak ada progress bar di accessibility tree — cek berkala sampai kartu video muncul.
- Tab bisa ditutup; generate tetap berjalan (tersimpan di akun).

## Download / Export
- Tombol "Download" di pemutar video → `.mp4` / `.mov` ke folder Download.
- Bisa di-share via link.

## Long-form (10–30 mnt) — TIDAK ADA NATIVE
Workaround (catat di SOP):
1. Potong notebook jadi beberapa bagian → generate masing-masing Explainer → gabung (CapCut/Clipchamp/FFmpeg).
2. Audio Overview + Slide Deck → render di tool lain (Google Vids, Canva, HeyGen).
3. Tools pendukung: CapCut, Clipchamp, Canva, HeyGen, FFmpeg, HandBrake.

## Sumber (Source)
- Jenis: PDF, DOCX, TXT, URL web, teks (Copied text), gambar, audio, Google Drive.
- Batas: 50 sumber / 200 MB / 500k kata per notebook.
- "Copied text" = tempel teks langsung → Insert. Paling andal untuk naskah buatan sendiri.

## Catatan Rebranding
- NotebookLM → Gemini Notebook (2026). URL lama tetap mengarah ke layanan sama.
- Beberapa akun berlabel "PRO" (fitur tambahan).
