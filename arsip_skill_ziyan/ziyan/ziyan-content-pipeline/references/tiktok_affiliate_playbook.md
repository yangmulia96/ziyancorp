# TikTok Affiliate Playbook (ZIYAN)

Dipelajari 2026-08-08 dari screenshot "Rating Kinerja Kreator" Bos (TikTok Affiliate) + riset sub-agent (disaring, sebagian sumber AI-halusinasi).

## RATING KREATOR (fakta dari screenshot Bos)
- Rating Bos = **245** (naik dari 227 di 07/12).
- Tiap konten "memenuhi syarat" (dapat views/engagement) → **+5 s/d +9**.
- Tiap minggu KALAU IDLE → **-5 s/d -8** ("Poin hadiah hangus, rating disesuaikan").
  Artinya: poin punya masa berlaku (rolling/expiring), bukan akumulasi permanen.
- **Net:** harus upload konsisten (min 2 video/hari) biar gain > loss. Berhenti seminggu = rating anjlok 20-30.

## KENAPA PENGURANGAN TERJADI
Bukan hukuman — cuma **kedaluwarsa poin lama**. TikTok paksa kreator tetap aktif. Selama konsisten, rating aman naik.

## ALGORITMA & KONTEN YANG CONVERT (fakta valid, cross-check)
- **Hook 3 detik**: sound efek + pertanyaan langsung → CTR 2x lipat (TikTok IQ).
- **Durasi 15-21 detik**: CTR rata-rata 18% (TikTok Business 2025-2026).
- **CTA**: "Link di bio 🔗" lebih aman dari link di video (hindari shadowban).
- **Format**: Before/After, Storytelling Product Demo, Unboxing, slide foto + teks.
- **Frekuensi**: min 2 video/hari jaga algoritma + rating.
- **Hashtag**: mix niche + broad (#koreandress #fyp #ootdhijab #fashionmurah).

## TIKTOK TIDAK BISA AUTO-UPLOAD
- Gak ada API gratis buat upload video. Scheduler FB/YT/X kita GAK bisa dipakai ke TikTok.
- Solusi ZIYAN: agent generate **video siap upload** (FFmpeg slide / Flow), Bos post manual.
- Tools legal: CapCut, TikTok Creative Center, link bio bawaan. Ilegal: bot auto-upload, spam comment (>3-5x/jam).

## REWARD VPS
Bos setuju beli VPS kalau penjualan TikTok naik. Track rating + order di Sheet tab "TikTok".

## WORKFLOW ZIYAN
1. Boss kirim foto/video produk + link Shopee.
2. Agent generate video 9:16 (FFmpeg / Flow) + caption hook + "link di bio".
3. Bos post ke TikTok manual.
4. Track dampak 2 minggu → ukur naik/turun penjualan.
