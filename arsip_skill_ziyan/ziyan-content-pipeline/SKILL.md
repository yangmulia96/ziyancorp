# ZIYAN Content Pipeline (Edukasi AI)

## Format Konten Edukasi (dari riset @ruangevolusiai / @data.frame)
- Durasi: 40-60 detik (TikTok/Reels)
- Gaya: hook teks besar + demo tools + CTA
- Tools: Canva (slide), screen record, CapCut (edit)
- Topik: Gemini Android, AI Coder, AI design, laptop lokal AI, jual prompt kit, Tree of Thoughts, AI detector

## Alur Produksi (ZIYAN otomatis)
1. **Ide** → RISA riset trending (HN, X, TikTok)
2. **Script** → 9router (combo riset) tulis hook + body + CTA
3. **Visual** → 9router-image (NanoBanana) bikin slide/poster
4. **Video** → 9router-video (Veo) atau CapCut manual
5. **Edit** → FFmpeg combine + subtitle
6. **Distribusi** → TikTok/Reels/Shorts (Bos upload manual, kita siapkan file)
