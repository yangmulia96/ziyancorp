📖 BAB 1: Menjinakkan Kanvas n8n (Apa itu JSON?)

(Ilustrasi: Gambar koper terbuka, di dalamnya ada label nama, umur, dan alamat)

Masalah terbesar pemula saat membuka n8n adalah melihat deretan teks aneh berbentuk kurung kurawal { } yang disebut JSON (JavaScript Object Notation).

Jangan Panik! Anggap JSON sebagai Koper. Ketika ada data masuk dari WhatsApp ke n8n, data itu dibungkus dalam "Koper JSON". Di dalam koper itu, ada label-label yang jelas:

{
  "nama_pengirim": "Budi",
  "isi_pesan": "Saya mau beli produk A",
  "nomor_hp": "0812345678"
}

Cara Mengambil Isi Koper di n8n: Jika kamu ingin memasukkan nama Budi ke Google Sheets, kamu tidak perlu mengetik manual. Di n8n, kamu cukup menggunakan trik Drag & Drop di panel kiri, atau mengetik ekspresi: 👉 {{ $json.nama_pengirim }}

TIPS VISUAL: Di kanvas n8n, selalu perhatikan panel sebelah kanan (Output). Itu adalah isi koper yang sedang dibawa oleh robotmu di langkah tersebut.

📖 BAB 2: Kunci Master (Webhook & HTTP Request)

(Ilustrasi: Kunci emas yang membuka gerbang ke berbagai logo sosmed/aplikasi)

Banyak orang menyerah pakai n8n karena aplikasinya tidak ada di daftar Node resmi. "Gimana cara sambungin ke TikTok? Kok gak ada logonya?"

Perkenalkan dua senjata rahasiamu:

1. Webhook (Penerima Bola)

Webhook adalah sebuah link URL kosong yang diberikan oleh n8n. * Fungsi: Menunggu aplikasi lain melempar data ke URL tersebut. * Contoh Kasus: Kamu pakai aplikasi kasir lokal. Kamu taruh link Webhook n8n di pengaturan kasir. Setiap ada pembeli, kasir melempar data ke Webhook, dan n8n otomatis menyimpan datanya ke Google Sheets.

2. HTTP Request (Pelempar Bola)

Jika Webhook itu menangkap, HTTP Request itu melempar. * Fungsi: Memaksa n8n mengetuk pintu aplikasi apa pun di dunia ini, asalkan aplikasi itu punya API. * Contoh Kasus: Mengirim pesan otomatis ke grup Telegram menggunakan API Bot Telegram, tanpa perlu node resmi.

📖 BAB 3: Memberi "Otak" pada Robot (IF & Loops)

(Ilustrasi: Robot di persimpangan jalan dengan rambu-rambu lalu lintas)

Robot yang pintar tidak hanya berjalan lurus. Ia harus bisa mengambil keputusan.

🚦 Node IF (Persimpangan Jalan)

Gunakan node IF untuk membuat aturan kondisi. * Syarat: JIKA (IF) isi_pesan mengandung kata "Komplain". * Jalur True (Benar): Kirim pesan ke grup Telegram Tim Support. * Jalur False (Salah): Balas dengan AI Auto-Reply (Katalog Produk).

🔄 Node Loop (Mesin Pengulang)

(Ilustrasi: Mesin pabrik yang memasukkan barang satu per satu ke dalam kardus) Apa yang terjadi jika kamu mengambil 50 baris data dari Google Sheets sekaligus? Jika kamu langsung memprosesnya, n8n bisa macet (error). * Solusi: Gunakan node Loop. * Cara Kerja: Loop akan mengambil 50 data tersebut, lalu memprosesnya SATU PER SATU. (Misal: Kirim WhatsApp ke pelanggan 1, tunggu 2 detik, lalu kirim ke pelanggan 2). Ini mencegah WhatsApp-mu diblokir karena spam.

📖 BAB 4: Risiko, Biaya, & Keamanan (Mitos vs Fakta)

(Ilustrasi: Tameng keamanan dengan simbol gembok dan koin)

Sebelum merilis "Pasukan AI"-mu ke publik, pastikan kamu paham aturannya:

  1. Apakah n8n Berbayar?
  2. Versi Cloud (dari pusat) berbayar bulanan.

  3. Solusi Kreator: Gunakan Self-Hosted (Install di VPS / Server sendiri). Biayanya hanya seharga sewa server (sekitar Rp 75.000 - Rp 150.000 / bulan), dan kamu bebas memproses jutaan data tanpa tagihan tambahan!

  4. Tagihan API OpenAI / Gemini Bisa Jebol?

  5. Mitos! Kamu bisa membatasi budget di dashboard OpenAI (misal maksimal $5/bulan).

  6. TIPS PRO: Jangan gunakan ChatGPT-4 untuk tugas sepele seperti merapikan teks. Gunakan GPT-3.5 atau Gemini Flash yang harganya hampir gratis (sepersekian sen dolar).

  7. Nomor WhatsApp Bot Bisa Diblokir (Banned)?

  8. Fakta! Mengirim 100 pesan promosi dalam 1 menit lewat WhatsApp Unofficial (WAHA) pasti akan diblokir Meta.
  9. Solusi: Gunakan Node Wait di dalam n8n. Beri jeda acak (15-30 detik) di antara setiap pengiriman pesan agar terlihat seperti manusia asli yang sedang mengetik.
