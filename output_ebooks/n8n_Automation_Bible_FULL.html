Menjinakkan Kanvas & Membaca JSON

Setelah n8n menyala, hal pertama yang akan membuatmu pusing adalah melihat format teks kurung kurawal. Inilah yang disebut JSON (JavaScript Object Notation).

💡
Analogi Koper Data

Setiap kali Node bekerja, ia mengoper sebuah "Koper". Di dalam koper itu ada label (Key) dan isi (Value). Tugasmu di n8n hanyalah memilih label mana yang mau diambil.

Struktur JSON Sederhana

Bentuk aslinya terlihat seperti ini:

{ "nama_pelanggan": "Budi Santoso", "total_belanja": 150000, "status": "LUNAS" }

Cara Mengambil Data di n8n (Ekspresi)

Jika kamu ingin mengirim pesan Telegram yang menyapa Budi, kamu tidak mengetik namanya manual. Kamu menggunakan Expressions. Caranya:

BAB 02 — KUNCI MASTER & LOGIKA

Webhook, HTTP Request, dan Routing

Bagaimana jika aplikasi yang ingin kamu hubungkan (misal: sistem Kasir lokal, TikTok, atau penyedia OTP) tidak ada ikon resminya di n8n? Inilah saatnya menggunakan "Kunci Master".

🎣

Webhook (Si Penangkap)

Node ini memberikanmu URL unik. Taruh URL ini di aplikasi luar (misal: setting Webhook di Shopee/Lynk.id). Setiap ada transaksi, aplikasi luar akan "melempar" data JSON ke URL tersebut.

🚀

HTTP Request (Si Pelempar)

Memaksa n8n mengetuk pintu aplikasi apa pun di dunia ini (API), seperti mengirim pesan Telegram secara kustom.

Memberi Otak pada Robot: IF vs Switch

Robot yang pintar harus bisa memilih jalur.

  • IF Node: Persimpangan 2 arah (Benar atau Salah). Gunakan jika kondisinya simpel: "Jika total belanja > 100rb, beri diskon, jika tidak, abaikan."
  • Switch Node: Persimpangan banyak arah. Sangat ampuh untuk Chatbot. "Jika pesan = 'Harga', ke jalur A. Jika 'Katalog', ke jalur B. Jika 'CS', ke jalur C."

Bahaya Spam: Mengapa Harus Ada Loops?

🚨
Peringatan Crash Server!

Jika Trigger membaca 500 baris Google Sheets sekaligus dan mengirimnya ke WhatsApp, server akan crash dan nomormu di-banned. Gunakan Node Loop (dulu bernama Item Lists / Split In Batches) untuk memprosesnya satu per satu dengan Node Wait di tengahnya.

BAB 03 — DATABASE MASTERY

Google Sheets vs MySQL vs Supabase

Seiring berkembangnya bisnis, mengandalkan Google Sheets untuk segala hal akan menjadi bencana. API Sheets lambat, rawan terhapus manual, dan tidak dirancang untuk menampung puluhan ribu baris data berat.

📊

Google Sheets (Level 1)

Cocok untuk draft konten, tracker keuangan harian, dan data yang butuh dibaca oleh admin manusia secara cepat. Batas aman: < 5000 baris.

🐘

PostgreSQL / MySQL (Level 2)

Database relasional sejati. Sangat cepat. Wajib digunakan jika kamu menyimpan log chat pelanggan, transaksi bot, atau ribuan Leads dari Form.

Supabase: Database Modern untuk n8n

Jika kamu malas mengurus server MySQL sendiri, Supabase adalah jawabannya. Ini adalah versi modern dari PostgreSQL dengan antarmuka yang semudah Google Sheets. Di n8n, kamu bisa menggunakan Node Supabase atau PostgreSQL bawaan.

BAB 04 & 05 — WHATSAPP BOT & RAG AI

Stable WAHA Chatbot & AI Vision

Membangun Bot WhatsApp sering menjadi ladang ranjau karena ancaman blokir (banned). Di tahun 2026, WAHA (WhatsApp HTTP API) adalah solusi open-source terbaik.

Best Practices Bot WhatsApp (WAHA) Anti-Banned

  • Jangan Pakai Nomor Pribadi: Gunakan nomor sekunder. Pemanasan (warming up) nomor baru selama 1 minggu (chat manual biasa) sebelum disambungkan ke bot.
  • Jeda Manusiawi (Wait Node): Jika melakukan blast/broadcasting, beri jeda acak 15-40 detik antar pesan.
  • Kirim Dokumen dari Drive: WAHA bisa mengirim File (PDF/Gambar). Cukup gunakan Node Google Drive (Download) ➔ lewati ke HTTP Request (Endpoint WAHA send-file) dengan data file binary (base64).

Take Over Chat (Manual Handoff)

Bot pintar harus tahu kapan ia bodoh. Jika pelanggan marah atau bertanya di luar SOP, buat alur Switch Node: Ubah status chat di Database menjadi "MANUAL". Jika status = MANUAL, matikan jalur AI, dan teruskan pesan langsung ke Telegram pribadi Admin (Human in the loop).

Kecerdasan Buatan (RAG & Vision)

Membaca KTP atau Struk Belanja tidak lagi butuh OCR kuno yang kaku.

👁️

AI Vision (Baca KTP/Receipts)

Terima kiriman foto di Telegram, oper image binary-nya ke Node OpenAI Vision / Gemini Pro Vision. Perintah: "Ekstrak NIK dan Nama dari KTP ini ke format JSON".

🧠

RAG (Retrieval-Augmented Gen)

Ingin AI menjawab sesuai PDF SOP perusahaanmu? Gunakan node Read PDF ➔ Embeddings (OpenAI) ➔ simpan ke Pinecone/Qdrant. Saat user bertanya, AI akan mencari jawabannya murni dari database PDF-mu, BUKAN halusinasi internet.
