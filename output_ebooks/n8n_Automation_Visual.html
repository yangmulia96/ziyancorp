BAB 01 — MENJINAKKAN KANVAS N8N

Apa itu JSON? (Jangan Panik)

Masalah terbesar pemula saat membuka n8n adalah melihat deretan teks aneh berbentuk kurung kurawal yang disebut JSON (JavaScript Object Notation).

💡
Anggap JSON sebagai Koper

Ketika ada pesan WhatsApp masuk, data itu dibungkus dalam "Koper JSON". Di dalamnya ada label jelas seperti: Nama, Isi Pesan, Nomor HP.

📦

Isi Koper (JSON)

{ "nama": "Budi", "pesan": "Order" }

🎯

Cara Mengambilnya

Ketik ekspresi: {{ $json.nama }}

BAB 02 — KUNCI MASTER APLIKASI

Menembus Batas dengan Webhook & HTTP Request

Banyak orang menyerah pakai n8n karena aplikasinya tidak ada di daftar Node resmi. "Gimana cara sambungin ke TikTok?" Gunakan dua senjata ini:

🎣

1. Webhook (Si Penangkap)

Link kosong dari n8n untuk menangkap data dari luar (misal: notifikasi pembayaran dari website toko onlinemu).

🚀

2. HTTP Request (Si Pelempar)

Memaksa n8n mengetuk pintu aplikasi apa pun di dunia ini (API), seperti mengirim pesan Telegram secara kustom.
