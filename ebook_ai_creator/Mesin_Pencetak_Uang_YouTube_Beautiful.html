Modul 1

Mindset & Arsitektur Pabrik Video AI

Transformasi dari pembuat konten manual menjadi pemilik pabrik media otomatis 24/7.

⚙️

Mengapa Era Konten Manual Sudah Berakhir?

Membangun pasokan konten tanpa batas tanpa rasa lelah dan tanpa menyewa tim editor mahal.

Channel Faceless YouTube (tanpa menampilkan wajah) adalah salah satu model bisnis digital paling menguntungkan saat ini. Namun, hambatan terbesarnya adalah konsistensi produksi. Mengedit 1 video Shorts bisa memakan waktu 1–2 jam.

Dengan Arsitektur Pabrik Video AI (Automated Video Pipeline), kita menghubungkan kecerdasan buatan ke dalam alur kerja n8n. Hasilnya: Anda cukup mengisi 1 baris ide di Google Sheets, dan sistem akan memproses seluruh pembuatan naskah, audio, klip video, subtitle, hingga mengunggahnya ke YouTube secara otomatis!

  • 100% Autopilot: Berjalan di cloud server tanpa menyalakan laptop setiap saat.
  • Skalabilitas Tanpa Batas: Kelola 5 hingga 10 channel YouTube Faceless sekaligus dari 1 dashboard n8n.
  • Bebas Hak Cipta: Menggunakan suara AI premium, musik Suno berlisensi, dan visual AI orisinal.
1

Trigger (Google Sheets)

Pemicu alur kerja berdasarkan jadwal atau status baris baru di tabel spreadsheet Anda.

2

Brain (ChatGPT API)

Riset keyword, buat naskah berstruktur JSON, buat prompt gambar/video, dan buat judul viral.

3

Voice & Visual (AI Engine)

Konversi teks ke suara natural via ElevenLabs/OpenAI TTS & ubah prompt menjadi video AI.

4

Publish (YouTube API)

Video dirender otomatis, ditambahkan subtitle, lalu diunggah ke YouTube sebagai Draft atau Public.

Modul 2

Command Center Google Sheets

Menjadikan Google Sheets sebagai otak pengendali & database seluruh channel Anda.

📊

Struktur Database Tabel Konten Utama

Google Sheets + n8n Trigger

Google Sheets bekerja sebagai Control Panel. Anda tidak perlu membongkar kode n8n setiap kali ingin membuat konten baru. Cukup perbarui data di tabel ini.

Nama Kolom Header Tipe Data Fungsi Otomasi n8n
ID_Konten TEXT Kode unik video (misal: FACT-001). Digunakan untuk penamaan file rendering.
Topik_Ide TEXT Ide kasar konten (misal: "5 Fakta Unik Luar Angkasa yang Mengerikan").
Status_Proses ENUM Nilai: READY, PROCESSING, DONE, ERROR. Trigger n8n hanya membaca baris 'READY'.
Naskah_ChatGPT LONG TEXT Diisi otomatis oleh n8n setelah ChatGPT API selesai menghasilkan script & visual prompt.
Audio_URL URL Link cloud storage hasil output MP3 dari ElevenLabs / OpenAI TTS API.
Video_Render_URL URL Link file MP4 akhir yang siap diunggah ke YouTube API.
💡
Aturan Emas Otomasi Trigger:
Pastikan n8n menggunakan node Google Sheets Trigger (On Row Updated/Added) dengan filter kondisi Status_Proses = READY. Begitu n8n mengeksekusi baris tersebut, ubah statusnya menjadi PROCESSING agar tidak terjadi duplikasi pengerjaan!
Modul 3

Otomasi Naskah dengan ChatGPT API (JSON Format)

Membuat script terstruktur dengan AI yang langsung bisa dipahami oleh node visual n8n.

🧠

Prompt Engineering Berbasis Output JSON Clean

Memaksa ChatGPT mengembalikan naskah dalam format kode yang presisi.

Agar n8n dapat memisahkan kalimat mana yang akan diubah menjadi suara (voiceover) dan kalimat mana yang dijadikan prompt gambar/video, kita wajib meminta ChatGPT untuk mengembalikan response berformat JSON (JavaScript Object Notation).

System Prompt ChatGPT API (Master Script Generator)
You are an expert viral YouTube Shorts scriptwriter. Generate a high-retention 30-second YouTube Shorts script about: "{{ $json.Topik_Ide }}" Strictly output ONLY a valid JSON object without markdown syntax or formatting wrapped inside brackets. Use the following JSON schema: { "title": "Viral YouTube Shorts Title with Emojis", "description": "SEO optimized description with #hashtags", "tags": ["tag1", "tag2", "tag3"], "voiceover_text": "Full continuous text to be read by TTS engine without visual notes.", "scenes": [ { "scene_number": 1, "audio_segment": "Hook text for scene 1", "visual_prompt": "Cinematic AI video prompt describing scene 1 in vivid detail, 8k, photorealistic --ar 9:16" }, { "scene_number": 2, "audio_segment": "Body text for scene 2", "visual_prompt": "Cinematic AI video prompt describing scene 2 in vivid detail, 8k, photorealistic --ar 9:16" } ] }
⚠️
Pengaturan Penting di Node OpenAI n8n:
Aktifkan fitur JSON Mode pada parameter API OpenAI (Gunakan model gpt-4o-mini atau gpt-4o) dengan menyetel response_format: { "type": "json_object" } untuk menjamin hasil 100% tidak pernah error parser!
Modul 4

Generasi Voiceover & Musik Latar AI (Suno & ElevenLabs)

Menghasilkan audio berkualitas radio sinematik secara otomatis via API Webhook.

🎙️

Arsitektur Pengolahan Suara & Background Music

Suara ekspresif dan musik bebas hak cipta buatan AI.

1

ElevenLabs API Node

Mengirimkan string voiceover_text dari ChatGPT ke ElevenLabs API. Menggunakan voice model seperti 'Adam' atau 'Rachel' untuk intonasi manusiawi.

2

Suno AI / Music API

Menghasilkan musik latar instrumental pendek tanpa vokal sesuai mood video (Dark Ambient, Energetic Corporate, Lo-Fi Chill) via API/Webhook.

3

Audio Mixer Integration

Menggabungkan file suara utama (Volume 100%) dengan musik latar Suno (Volume 12-15%) secara presisi agar dialog tetap terdengar jelas.

Prompt Generator Lirik & Style BGM Suno AI
[Style: Cinematic Dark Tension Instrumental, Deep Bass, Suspenseful Synth Strings, 110 BPM, No Vocals] [Instrumental Breakdown] Dramatic opening pulse, crescendo building up with subtle percussion ticks, transitioning to smooth mysterious background atmospheric sound suitable for documentary voiceover.
Modul 5

Otomasi Generasi Video AI & Stitching Rendering

Menggabungkan klip video AI, sulih suara, dan subtitle animasi otomatis.

🎬

Integrasi Engine Video AI & Cloud Renderer

Creatomate / Shotstack / FFmpeg API

Untuk menggabungkan klip video, audio, dan teks caption animasi berwarna-warni secara otomatis, kita menggunakan Cloud Video Rendering Service seperti Creatomate API atau Shotstack API melalui n8n HTTP Request node.

Visual Provider Keunggulan Metode Integrasi n8n
Luma Dream Machine / Runway API Kualitas gerak video AI 3D/Realistis paling tinggi. HTTP Request POST ke endpoint Async Video Generation.
Leonardo AI / Midjourney API Gambar konsisten, siap diubah jadi Motion Video 9:16. REST API Payload dengan Webhook Callback.
Creatomate Cloud Renderer Auto-subtitle Word-by-Word ala Alex Hormozi + Auto Edit. Official n8n Node atau JSON Template Render API.

Langkah A: Gen Video AI

n8n mengulang (loop) array scenes dari JSON ChatGPT dan mengirim visual_prompt ke API Generator Video.

Langkah B: Subtitle Synchronization

Engine Renderer mendeteksi timestamp audio dari ElevenLabs untuk menampilkan teks kata demi kata secara otomatis di layar.

Langkah C: Export File MP4

Server Cloud menyelesaikan rendering video dalam waktu kurang dari 60 detik dan mengembalikan URL download MP4 siap pakai.

2

Hubungkan ke Node YouTube
